# Assets

This project intentionally ships **no external models, image textures or
HDRI files**. The environment is generated by Python inside Blender.

## Generated content

- **Architecture** — lotus petal shells, ribs, central dome, stage arch,
  balconies, stairs, planters, pool coping, deck, signage. Built from
  bmesh primitives, parametric surfaces and curve tubes in
  `scripts/tf_arch.py`.
- **Plants** — coconut palms, fan palms (traveller's palm style), monstera,
  banana, bird of paradise, heliconia, hibiscus, croton, ferns and
  groundcover. All leaves/trunks are custom meshes in
  `scripts/tf_nature.py`.
- **Materials** — white ceramic, pearl shell, iridescent glass, basalt,
  palm bark, coconut, leaf greens, flowers, water, pool caustics, foam,
  LED screen, neon, warm bulbs and matte sign panel. Node-based in
  `scripts/tf_core.py`.
- **Sky** — procedural gradient, sun halo and soft cumulus layer in
  `scripts/tf_look.py`. No HDRI.
- **Signage** — 3D text using the locally installed
  `LeagueSpartan-Bold.otf` font. The font file is not redistributed here.

## Reference material

The eight JPGs in `../visual reference/` are the art-direction references.
They are **not** used as textures or image planes and are not part of the
render. Do not redistribute them without checking their original licence.

## Reuse

All generated geometry is scene-local. To reuse a plant, open
`tropical_festival_courtyard.blend`, go to the `MASTERS` collection, and
copy one of the hidden master objects (`PALM_TALL`, `MONSTERA`, `BANANA`,
`BIRD`, `FAN_PALM`, `CROTON`, etc.). The placed copies live in
`04_TROPICAL_TREES`, `05_TROPICAL_PLANTS` and `Groundcover`.
